Arcuva Remote desktop

Apple Vision Pro 曲面远端桌面客户端 · 技术支持

Arcuva 把你的 Windows 电脑变成一块悬在眼前的曲面超宽屏：弧度、尺寸、观看距离都能自己定，平铺到环绕皆可。这里是使用帮助与联系方式。

曲面超宽屏弧度从平面无级调到同心圆包裹，尺寸与观看距离随手改，会话中也能切。
分辨率预设2560×1080、3440×1440、5120×1440、7680×2160，并实时给出每度像素数。
注视即点看着目标捏合点击；快速两下双击；捏住不放右键。直接上手十指触控也行。
两种视图沉浸空间（可调暗环境、躺着用）或普通窗口（与 Safari、信息等并排）。
键盘与剪贴板内置 87 键 PC 键盘，Ctrl/Alt/Win 可粘住，一键 Ctrl+Alt+Del；文本双向同步。
办公电脑友好支持远程桌面网关，也能直连内网地址；可导入 IT 部门给的 .rdp 文件。

首次连接三步

  1. 在 Windows 电脑上打开 设置 → 系统 → 远程桌面，打开「启用远程桌面」，记下电脑名或 IP，以及能登录的用户名和密码。
  2. 在 App 的「电脑」页点 +，填入地址、用户名、密码后存储。
  3. 点「连接」。首次会要求确认证书，选「信任一次」即可（Windows 默认使用自签名证书）。

不支持 Windows 10 / 11 家庭版：家庭版无法接受远程桌面连接，需要 Pro、企业版或教育版。

常见问题

连不上电脑怎么办？

按顺序检查：① Windows 是否已开启远程桌面，且不是家庭版；② 电脑名或 IP 是否写对，端口默认是 3389；③ 电脑是否处于开机、未休眠状态；④ 本机防火墙是否放行了远程桌面；⑤ 从公司外面连，通常需要走公司的远程桌面网关。

为什么会提示「本地网络」权限？

连接同一局域网里的电脑需要本地网络权限。它只用于访问你填写的那台电脑地址，不会扫描网络，也不会把任何数据发往外部服务器。

画面上的字看不清？

先试试调大分辨率预设（例如 5120×1440）并把弧度和观看距离调到舒服的位置；文字类工作建议打开 mipmap 与 MetalFX 锐化。还可以使用「局部放大」只放大一小块区域，而不改变 Windows 端的分辨率。

怎么像用触控屏那样直接上手？

在沉浸空间里可以直接用手指触控画面，最多支持十指；也可以切换「鼠标指针模式」，把整块屏幕当触控板使用。

可以怎么用成公司的标准连接方式？

在「电脑」页点「导入 .rdp 文件」，读取 IT 部门给的 .rdp 连接文件即可；也可以在网关设置里填好公司的远程桌面网关地址。

App 会收集我的数据吗？

不会。Arcuva 没有账号体系、没有服务器、没有第三方 SDK，所有设置只保存在本机，密码存在设备钥匙串里。详见隐私政策。
